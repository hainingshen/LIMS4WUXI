# 前端原型设计提示词（Claude Design）

本文档是给 Claude Design 用的提示词。目标：生成一套高保真前端原型，用于向客户确认整体开发方案、视觉风格、关键页面信息架构和移动端体验。

直接复制下方"提示词正文"全部内容到 Claude Design。需要的引用素材（fixture / CSV / 标识）已在文末附录列出。

---

## 提示词正文

```
你将为一个名为 LIMS4WUXI 的医疗器械检测实验室信息管理系统生成高保真前端原型。这是给真实客户做方案确认的设计稿，必须美观、专业、可信、贴合医疗检测场景，不能是模板化通用后台。

# 一、项目背景

客户：无锡市南京大学锡山应用生物技术研究所（医疗器械检测实验室）
业务：医疗器械生物相容性、微生物、包装、物理、化学检测
资质：CMA / CNAS 双重认证
体量：内部 50-100 人，客户单位上千家
痛点：销售-技术-合同-样品-实验-报告信息重复录入；项目进度不透明；报告生成弱；非标方法报价前缺评审；付款门禁不严

# 二、技术与组件约束

技术栈（必须遵守）：
- React 18 + TypeScript + Vite
- Ant Design 5（桌面端）
- Ant Design Mobile 5（移动端）
- formily 2.x（动态表单）
- Zustand（状态管理）
- TanStack Query（数据获取）
- 响应式 PWA：一套代码，桌面端 / 平板 / 手机自适应

原型实现要求：
- 输出为单文件 HTML（含 CDN 引入的 React + AntD + Tailwind），可直接在浏览器打开。
- 不要依赖本地构建，所有资源通过 CDN 加载。
- 用 React 组件化写法，但不引入构建系统。
- 用 antd@5 桌面端组件 + antd-mobile@5 移动端组件，按 useMediaQuery 断点切换。
- 字体：Noto Sans SC（中文）+ Inter（英文/数字）；CDN 引入。
- 图标用 @ant-design/icons 通过 CDN。
- 图表用 ECharts 5 通过 CDN。

# 三、视觉风格

整体气质：专业、严谨、科研感、现代、留白克制。绝不油腻、绝不老旧政府风、绝不通用后台模板。

色彩系统：
- 主色 Primary: #1A5FB4（深科研蓝，对应医疗器械专业感）
- 辅助色 Accent: #00A8A8（青绿，用于强调和数据高亮）
- 成功 Success: #10B981
- 预警 Warning: #F59E0B
- 风险 Danger: #EF4444
- 中性灰阶: #0F172A（深文字）/ #475569（次文字）/ #94A3B8（占位文字）/ #E2E8F0（分割线）/ #F8FAFC（背景）
- 卡片背景：纯白 + 1px 浅灰边框 + 4px 圆角的轻量阴影 box-shadow: 0 1px 3px rgba(15, 23, 42, 0.06)

排版：
- 中文 Noto Sans SC，英文/数字 Inter
- 标题字重 600，正文 400，标签 500
- 行高 1.6，正文 14px，标题 16-20px，大数字 24-36px
- 字符间距：中英文混排时英文用 letter-spacing: 0.01em
- 严格栅格：左右各 24px 内边距，模块间 16-24px 间距

布局：
- 桌面端：左侧固定 240px 收起 64px 侧边导航 + 顶部 56px 固定头 + 内容区域
- 移动端：底部 Tab Bar 4-5 项 + 顶部 44px 状态栏样式头
- 卡片化信息组织，避免大段表格直接铺满
- 重要数据用 Statistic 大数字突出
- 状态全部用 Tag + 颜色编码（正常绿、预警黄、风险红）
- 中英文双语字段并列展示，英文用 #475569 次要灰色

品牌头部：
- 内部端 Logo 左侧显示"南京大学锡山应用生物技术研究所 LIMS"
- 客户门户 Logo 显示"NJU XISHAN LIMS 客户服务平台"
- 头部右上角显示当前用户、角色、CMA/CNAS 资质徽章

# 四、需要生成的页面（12 个核心 + 4 个移动端）

每个页面都必须用真实的业务数据（见第六节示例数据），不要用 Lorem Ipsum 或"示例 1/示例 2"。

## 桌面端页面（19 个）

### P1 - 客户门户登录
- 左侧 60% 是品牌区，深蓝渐变背景，展示实验室全景照片或抽象的医疗器械检测插画
- 实验室标语："专业 严谨 可信赖的医疗器械检测伙伴"
- CMA / CNAS / GLP 三个资质徽章横排
- 右侧 40% 是登录表单，纯白背景
- 字段：手机号 / 邮箱、密码、记住我、忘记密码、扫码登录二维码 Tab
- 登录按钮深蓝主色填充，全宽
- 底部小字："如需开通客户账号，请联系 med@sudatest.com 或致电 (0512)65880038"

### P2 - 客户门户首页（PortalDashboard）
- 顶部欢迎条：左侧大字 "您好，[委托单位名]"，右侧四个 Statistic 卡片（进行中项目 / 待付款报告 / 本月送检 / 累计报告）
- 中段两列布局：
  - 左 60%：项目卡片列表，每张卡片显示项目编号、样品名（中英文）、检测项目、当前阶段（进度条 5 段 = 受理 → 样品到达 → 试验 → 报告 → 发放）、计划完成日期
  - 右 40%：通知公告 + 我的待办（确认协议 / 草稿预览 / 付款提醒）
- 大字按钮 "新建送检单"，悬浮在右下角，深蓝主色，带阴影
- 项目卡片支持点击进入项目详情

### P3 - 送检单新建表单（PortalSubmissionNew，核心复杂表单）⭐
这是本系统最复杂的表单，必须充分展示 formily 动态表单能力，分 8 个 PART 步进式或 Tab 式：

- PART 1 委托方信息：委托单位（中英文双行）、地址（中英文）、制造商（中英文）、制造商地址、联系人、电话、邮箱、电子报告接收邮箱、报告/发票寄送信息
- PART 2 报告要求：是否 GLP（开关）、是否要纸质盖章件（开关）、计划书语言（CHS/ENG/BOTH 三选一卡片）、报告语言
- PART 3 样品处置：送检样品总数（数字+单位）、样品处置方式（破坏丢弃 / 回寄未使用 / 其他，单选卡片，选其他时显示文本框）
- PART 4 样品基本信息：样品名称（中英文）、灭菌状态（5 选 1 下拉，附图标）、CAS、型号、规格、批号（带"提交后硬锁定"提示）、材料、包装材料、物理状态（固/液/粉/其他）、颜色、密度、稳定性、溶解度、保存条件、预期用途、附加信息
- PART 5 生物相容性额外信息：前处理要求、非灭菌额外处理、是否可切割、检测部位（中英文）、工作温度（°C）、是否耐 50°C、累积接触时长（A/B/C 三选一）、浸提依据（表面积/重量/N/A）、表面积、最薄厚度、特别说明
- PART 6 GLP 声明（条件显示，仅在 PART 2 选 GLP=YES 时出现）：FDA 21 CFR 58 表征确认勾选 + 确认人 + 确认时间
- PART 7 生物相容性试验矩阵：表格形式列出 11 个试验项（细胞毒性/刺激/致敏/急性毒性/热原/亚急性毒性/亚慢性毒性/慢性毒性/遗传毒性/植入/血液相容性），每行可勾选 + 选方法 + 选浸提介质 + 选参照标准 + 备注
- PART 8 其他试验：微生物/包装/物理/化学，类似矩阵

顶部步进条显示进度。底部"保存草稿 / 上一步 / 下一步 / 提交"，右侧"实时预览"按钮可打开抽屉显示填写汇总。

字段必填用红 * 标记，悬停 i 图标显示中英文双语帮助提示（来自送检单 Ver.15 的 notes 列）。

### P4 - 客户项目详情（PortalProjectDetail）
- 顶部面包屑 + 项目编号 + 状态 Tag + 健康度徽章
- 项目时间线（垂直时间轴）：14 个状态节点（DRAFT → ACCEPTED → ... → ARCHIVED），已完成节点蓝色实心，当前节点青色高亮 + 脉动，未来节点灰色空心
- 三列：项目信息（项目编号、类型、资质、负责人）、样品信息卡（含样品照片缩略图、关键字段）、检测项目清单
- 报告区：报告状态卡片，未付款时显示"草稿可预览"按钮 + "正式版本已锁定，付款后解锁"红色提示
- 文件区：合同、协议、补充协议、原始记录摘要的附件列表
- 操作区：再次签署补充协议 / 联系业务

### P5 - 报告草稿预览（PortalReportPreview）
- 全屏文档预览，模拟真实报告版式
- 大水印对角线"草稿 / DRAFT - 非正式报告"半透明灰
- 顶部工具条：仅显示放大/缩小/页码，禁用下载和打印（按钮置灰带"付款后解锁"tooltip）
- 报告内容用真实样例（无菌检查报告）：实验室封面、声明页、检测信息表格、检测结果表格、结论、签字栏（含"未签发"占位）
- 右侧浮动行动条：联系业务、申请加急

### P6 - 内部端工作中心（InternalWorkCenter）⭐核心展示页
这是给管理层最有冲击力的页面，必须做得最精致：

- 顶部 4 个大 Statistic 卡片：项目健康度概览（饼图：正常 X / 预警 Y / 风险 Z）、我的待办、超期任务、本周完成
- 中段三列：
  - 左 30%：项目健康度分布（饼图） + Top 5 风险项目卡片列表（项目编号 + 健康度评分 + 主要扣分原因）
  - 中 40%：当前阻塞看板（按阻塞类型分组：待审批 X / 缺物料 Y / 设备冲突 Z / 待客户确认 W），每个阻塞卡片显示 Owner 头像、阻塞描述、预计恢复时间、影响范围
  - 右 30%：人员负荷热力图（横轴日期、纵轴检测员姓名，颜色深浅表负荷率）
- 下段：进度趋势图（双折线：计划完成量 vs 实际完成量，6 周趋势）
- 工作中心顶部筛选：项目类型 / 客户 / 负责人 / 状态 / 紧急程度（加急/普通）
- 健康度评分卡片悬停显示扣分明细（"-15 连续 2 天无进展 / -10 待审批阻塞 1 项 ..."）

### P7 - 内部样品收样台（InternalSampleDesk）
专为样品管理员设计，必须像扫码工作站：

- 左 60%：操作区
  - 大输入框 + 扫码图标：输入或扫描送检单号 / 样品标签
  - 自动加载送检信息卡片（委托单位、样品名、规格、批号、数量、储存条件）
  - 核验勾选清单（名称匹配 / 数量匹配 / 包装完好 / 储存条件 / 冷链温度记录）
  - 异常处理按钮（拍照上传 / 联系客户 / 退回受理）
  - 样品照片上传区（最多 6 张，缩略图）
  - 大按钮 "样品预入库" → "样品正式入库" 两步
- 右 40%：今日待收样品队列（卡片列表，按预计到达时间排序），已收样品历史

### P8 - 内部项目详情与状态机（InternalProjectDetail）
- 顶部项目基础信息 + 项目类型 Tag（STD_ACCREDITED 绿 / STD_NON_ACCREDITED 黄 / NON_STANDARD 红）
- 状态机可视化：横向流程图（DRAFT → ACCEPTED → ... → ARCHIVED），当前节点高亮，guards 未满足的节点显示锁图标
- 左侧 Tab：基础信息 / 样品 / 试验计划 / 工单 / 报告 / 收款 / 档案 / 审计日志
- 右侧固定栏：负责人卡片（业务 Owner / 技术 Owner / SD 头像 + 联系方式）、健康度评分卡片、付款状态卡片、阻塞清单

### P9 - 内部报告审核页（InternalReportReview）⭐
- 左 60%：报告文档预览（与 P5 类似但带 QC/QA/SD 编辑批注）
- 右 40%：审核侧栏
  - 当前阶段（QC_REVIEWING 蓝 Tag）+ 已完成阶段卡片堆叠
  - 字段映射对照表（左原始记录字段 → 右报告字段，可点击跳转）
  - 历史批注列表（QC 提的、QA 提的）
  - 审核操作区：意见输入框 + 通过按钮（绿）+ 驳回按钮（红）
  - 付款门禁状态卡（红色锁 / 绿色开锁 / 黄色绿色通道）
- 顶部工具条：版本切换（v1 旧 / v2 当前修订）

### P10 - 内部财务收款登记（InternalPaymentReceipts）
- 顶部 4 个 Statistic：本月已到账金额 / 待到账金额 / 绿色通道笔数 / 异常冲销
- 左 50%：未结款项目列表（项目编号 / 客户 / 合同金额 / 已收 / 应收 / 到期日 / 状态 Tag）
- 右 50%：登记到账表单
  - 项目下拉选择
  - 金额（大数字输入）
  - 收款方式（银行转账 / 现金 / 其他）
  - 凭证文件上传
  - 备注
  - 大按钮"确认到账并解锁报告下载"，提交后弹窗显示影响的报告列表

### P11 - 内部设备预约日历（InternalDeviceCalendar）
- 顶部设备切换 Tab（HPLC-001 / GC-MS-002 / 培养箱-003 ...）
- 周视图 + 月视图切换
- 时间槽 30 分钟粒度，颜色编码（蓝 = 已预约内部 / 灰 = 外部预约 / 红 = 维护停机 / 白 = 空闲）
- 点击空闲槽弹出预约表单：预约人（自动带入）/ 预约时间段 / 工单号 / 检测项目 / 用途
- 已预约槽悬停显示详情 + 覆盖外部预约按钮（弹窗填覆盖原因，触发通知）
- 右侧浮动"我的预约"列表

### P12 - 内部系统配置（InternalSystemConfig）
- 左侧分类导航：字典管理 / 权限矩阵 / 角色管理 / 业务规则 / 阈值参数 / 模板管理
- 右侧主区：以"阈值参数"为例展示
  - 配置项表格：键 / 值 / 类型 / 分类 / 可编辑角色 / 描述
  - 行内编辑，保存按钮，保存后浮层提示"已保存，1 分钟内全网生效"
  - 右上角"导出 CSV / 从 CSV 导入"
- 业务规则页：rule_code + name + trigger_type + condition_expr（Aviator 表达式，代码高亮）+ enabled 开关

### P13 - 统一变更中心（InternalChangeRequests）
- 顶部筛选：目标类型（协议 / 样品 / 项目 / 报告）、变更类型、状态、申请人、申请日期
- 左侧列表：变更申请卡片，显示申请编号、目标对象编号、变更摘要、锁定策略 Tag、当前审批节点
- 右侧详情：
  - 字段级 diff 表格：字段名 / 原值 / 新值 / 锁定策略 / 生效方式
  - 目标对象当前状态卡：是否合同签署、是否报告签发、是否归档
  - 审批时间线：申请、审批、驳回、生效、归档
  - 操作区：提交、审批通过、驳回、查看目标对象
- 硬锁字段必须显示红色锁图标和"需重新签发或补充协议"提示，不允许出现直接保存按钮

### P14 - 留样管理（InternalSampleRetention）
- 顶部 Statistic：当前留样数、30 天内到期、待处置、已销毁
- 主表：留样编号、样品编号、项目编号、样品名称、留样数量、位置、保存条件、到期日、状态
- 右侧抽屉详情：留样照片、登记人、登记时间、处置计划、关联报告、付款门禁状态
- 操作按钮：登记留样、延期、退还、销毁、转长期档案
- 到期行用黄色背景，逾期行用红色左边框；处置操作必须二次确认并要求填写原因

### P15 - 报告注册中心（InternalReportRegistry）
- 顶部组合搜索：报告编号、项目编号、客户、模板类型、签发日期、发放状态
- 主表：报告编号、当前版本、项目、客户、模板、签发人、签发时间、付款门禁、发放次数
- 行展开展示版本历史：v1/v2、状态、重新签发原因、DOCX/PDF 文件、数据快照
- 右侧发放日志：预览、下载、邮件、批量下载、绿色通道，显示操作者、对象、时间、文件哈希
- 顶部批量下载按钮生成异步任务，不直接在页面同步打包

### P16 - 报告模板管理（InternalReportTemplates）
- 顶部 Tabs：合同模板、流转单模板、中文报告、英文报告、专项报告
- 模板卡片：模板名称、代码、版本、自动化等级 A/B/C、状态、发布时间、适用范围
- 版本抽屉：历史版本列表、发布人、发布说明、关联报告数量
- 操作：上传新版本、发布、废止、预览模板
- A 级模板显示字段映射完整度，B 级显示待人工补录字段，C 级显示"人工编辑受控模板"

### P17 - 设备文件页（InternalDeviceFiles，嵌入设备详情）
- 作为设备详情的"文件 / 证书" Tab，不做独立网盘样式
- 顶部设备卡：设备编号、名称、状态、负责人、使用位置、是否计量
- 文件表格：文件类型、文件名、版本、有效期、是否当前有效、上传人、上传时间
- 证书类文件有效期即将到期用黄色 Tag，已过期用红色 Tag
- 操作：上传文件、设为当前版本、作废文件、下载查看；检测员视角只读

### P18 - 主数据管理（InternalMainData）
- 左侧树：组织架构、用户、角色、系统字典、节假日
- 组织架构页：部门树 + 人员列表 + 岗位/角色绑定
- 用户页：账号、姓名、部门、角色、状态、最后登录时间
```
