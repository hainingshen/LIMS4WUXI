# 开工前最终补齐记录

## 1. 背景

本记录用于承接开工前最后复核。复核发现文档主体已经可以指导一期系统开发，但 `07_API与界面契约.md` 与 `specs/openapi.yaml` 存在接口漂移，且 specs 校验脚本尚未落地。为便于迁移到全新开发机后直接开工，本轮将机读契约和校验脚本补齐。

## 2. 已补齐内容

### 2.1 OpenAPI 对齐

`specs/openapi.yaml` 已从 45 个 path、38 个 schema 扩展到 80 个 path、77 个 schema。

新增或补齐的主要资源包括：

- 鉴权：`/auth/refresh`、`/auth/me`。
- 客户与门户账号：`/customer-orgs`、`/portal-users`。
- 送检动作：`/submissions/{id}/accept`、`/submissions/{id}/split-projects`。
- 报价与合同：`/quotations`、`/projects/{id}/quotations`、`/contracts`、`/contracts/{id}/mark-signed`。
- 样品和方案：`/samples/{id}/stock-in`、`/study-plans`、`/study-plans/{id}/submit-review`、`/study-plans/{id}/dispatch`。
- 原始记录：`/raw-records`、`/work-orders/{id}/submit-raw-record`、`/raw-records/{id}/review`。
- 报告动作：`/reports/{id}/submit-qc`、`/reports/{id}/issue`。
- 收款与绿色通道：`/payment-receipts`、`/green-channel-requests`。
- 设备和预约：`/devices`、`/device-bookings`、`/device-bookings/{id}/override`。
- 库存：`/inventory-batches`、`/inventory-transactions`。
- 工作中心：`/work-center/summary`、`/work-center/projects`、`/work-center/blockers`、`/work-center/resource-load`、`/work-center/trends`。
- 档案和字典：`/archive-items`、`/dictionaries`。

同时已补 `components.securitySchemes.bearerAuth` 和全局 JWT bearer 安全要求。登录和刷新 token 接口显式设置为公开接口。

### 2.2 校验脚本

新增：

- `scripts/checks/csv-foreign-key.py`
- `scripts/checks/drift-detector.py`

`csv-foreign-key.py` 校验：

- `roles.csv` 角色唯一性。
- `permission_matrix.csv` 的 `actionCode + roleCode` 唯一性和角色外键。
- `dictionaries.csv` 的 `dictCode + itemCode` 唯一性。
- `submission_ver15_fields.csv` 的字段唯一性、字典引用和 `lock_policy` 引用。
- `test_catalog.csv` 和 `sterility_report_mapping.csv` 的关键字段唯一性。
- `openapi.yaml` YAML 解析、JWT security scheme 和内部 `$ref`。
- `specs/fixtures/demo_project.json` 必要顶层对象。

`drift-detector.py` 校验：

- `07_API与界面契约.md` 中的资源和动作接口已进入 `specs/openapi.yaml`。
- `10_工作中心详细设计.md` 中的工作中心 API 已进入 `specs/openapi.yaml`。
- `openapi.yaml` 已声明全局 bearer 鉴权。
- 前端路由 `requiredRoles` 均存在于 `roles.csv`。
- Markdown 本地链接无断链。

## 4. 新开发机迁移后操作

迁移全部文档和脚本到新开发机后，先执行：

```powershell
python -m pip install -r .\scripts\checks\requirements.txt
python .\scripts\checks\csv-foreign-key.py
python .\scripts\checks\drift-detector.py
```

两条命令必须通过后再做以下动作：

1. 根据 `specs/openapi.yaml` 生成后端接口骨架、前端 API client 和 mock。
2. 根据 `roles.csv`、`permission_matrix.csv`、`dictionaries.csv` 生成初始种子数据。
3. 根据 `submission_ver15_fields.csv` 生成 `form_schema` 初始版本。
4. 按 [13_迭代里程碑与上线切换.md](13_迭代里程碑与上线切换.md) 从 S1 开始开发。
