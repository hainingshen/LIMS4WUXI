## 使用建议

- 给客户沟通一期范围时，优先使用 `01_项目基础开发说明.md` 和 `02_业务流程与一期范围.md`。
- 给 Vibe Coding 或开发团队生成代码时，必须优先使用 `README.md`、`00_技术栈与工程约定.md`、`06_数据模型与状态机.md`、`07_API与界面契约.md`、`specs/openapi.yaml` 和 `specs/` 下的 CSV。
- 给开发团队拆分任务时，使用 `03_功能需求与数据清单.md`、`04_角色权限与审批规则.md`、`10_工作中心详细设计.md`。
- 准备上线、迁移和验收时，优先使用 `05_数据迁移与实施边界.md` 和 `16_部署与发布手册.md`。
- 与客户沟通"快速迭代"承诺时，使用 `17_修改生效SLA与可配置项清单.md`。
- 复盘技术栈决策时，使用 `18_第四轮决策记录.md`。
- 迁移到新开发机或启动 S1 前，必须阅读 `21_开工前最终补齐记录.md` 并运行 `scripts/checks/` 下两个校验脚本。
- 需要客户继续答复的问题，单独使用 `客户需确认的需求冲突与工作流问题.md`。
