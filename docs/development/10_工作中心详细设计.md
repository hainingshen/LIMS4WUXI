# 工作中心详细设计

## 1. 设计目标

工作中心不是单纯展示完成百分比，而是帮助业务、技术负责人和管理层看到：

- 项目是否健康。
- 当前卡在哪里。
- 谁负责推动。
- 风险是在扩大还是收敛。
- 人员和资源是否过载。

## 2. 页面模块

| 模块 | 说明 |
| --- | --- |
| 项目健康度 | 正常、预警、风险，展示评分和原因 |
| 当前卡点 | 阻塞清单、阻塞类型、影响范围、预计恢复时间 |
| 责任链 | Owner、协作人、上级抄送对象 |
| 人员负荷 | 每人待办、执行中、超期任务和预计工时 |
| 时间趋势 | 计划与实际、延期变化、风险数量变化 |
| 我的待办 | 当前用户审批、执行、审核任务 |

## 3. 健康度评分

默认满分 100 分，每日定时计算，也可由项目关键动作触发重算。

扣分规则：

| 条件 | 扣分 |
| --- | --- |
| 连续 2 天无进展 | -15 |
| 任一关键里程碑超期 | -30 |
| 普通任务超期 | 每项 -8，最高 -24 |
| 存在未关闭阻塞 | 每项 -10，最高 -30 |
| 高风险阻塞 | 额外 -15 |
| 责任人未指定 | -20 |
| 资源负荷超过 120% | -10 |
| 预计完成时间晚于合同交付时间 | -30 |
| 样品异常未处理 | -20 |
| 非标评审未完成却尝试报价 | 直接标红 |

状态阈值：

| 分数/条件 | 健康状态 |
| --- | --- |
| `score >= 85` 且无强制红色条件 | 正常 |
| `70 <= score < 85` | 预警 |
| `score < 70` | 风险 |
| 任一强制红色条件 | 风险 |

强制红色条件：

- 关键里程碑超期。
- 合同交付期已无法满足。
- 非标项目未审批却进入报价或签约。
- 报告签发后付款门禁被绕过。
- 动物试验未过伦理却下发。

## 4. 阻塞记录

阻塞必须结构化，不能只写“协调中”。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `blockerType` | enum | 是 | 阻塞类型 |
| `severity` | enum | 是 | `LOW`、`MEDIUM`、`HIGH` |
| `description` | text | 是 | 具体问题 |
| `impactScope` | text | 是 | 影响哪些任务或报告 |
| `expectedRecoveryAt` | datetime | 是 | 预计恢复时间 |
| `ownerUserId` | uuid | 是 | 唯一主责人 |
| `collaboratorIds` | uuid[] | 否 | 协作人 |
| `status` | enum | 是 | `OPEN`、`IN_PROGRESS`、`RESOLVED`、`CLOSED` |
| `resolution` | text | 条件必填 | 关闭时必填 |

阻塞类型字典：

- `PENDING_APPROVAL`：待审批。
- `MISSING_SAMPLE`：样品未到或样品异常。
- `MISSING_MATERIAL`：缺物料、标准品、试剂。
- `DEVICE_CONFLICT`：设备冲突。
- `STAFF_UNAVAILABLE`：人员不可用。
- `TECHNICAL_RISK`：技术风险。
- `CUSTOMER_CONFIRMATION`：待客户确认。
- `SUBCONTRACT_DELAY`：分包延迟。
- `PAYMENT_BLOCKED`：付款阻塞。
- `REPORT_REWORK`：报告返工。
- `OTHER`：其他。

## 5. Owner 规则

- 每个项目必须有业务 Owner 和技术 Owner。
- 每个工单必须有唯一执行 Owner。
- 每个阻塞必须有唯一推进 Owner。
- 协作人可以多人，但不能替代 Owner。
- Owner 变更必须记录原因。

超期通知：

- 任务进入预警：通知 Owner。
- 任务超期：通知 Owner，并抄送其上级或负责人。
- 项目变红：通知业务负责人、技术负责人和管理层观察账号。

## 6. 趋势指标

按周生成趋势快照：

| 指标 | 说明 |
| --- | --- |
| `plannedTasks` | 计划完成任务数 |
| `completedTasks` | 实际完成任务数 |
| `overdueTasks` | 超期任务数 |
| `openBlockers` | 未关闭阻塞数 |
| `riskProjects` | 风险项目数 |
| `avgDelayDays` | 平均延期天数 |
| `resourceLoadRate` | 资源负荷率 |

趋势图至少支持：

- 单项目趋势。
- 按团队趋势。
- 按项目类型趋势。
- 计划完成量 vs 实际完成量。
- 风险数量变化。
- 平均延期天数变化。

## 7. 工作中心 API

| 接口 | 说明 |
| --- | --- |
| `GET /api/v1/work-center/summary` | 健康度、待办、风险汇总 |
| `GET /api/v1/work-center/projects` | 项目列表和筛选 |
| `GET /api/v1/work-center/blockers` | 阻塞清单 |
| `POST /api/v1/work-center/blockers` | 新增阻塞 |
| `PATCH /api/v1/work-center/blockers/{id}` | 更新阻塞 |
| `POST /api/v1/work-center/blockers/{id}/close` | 关闭阻塞 |
| `GET /api/v1/work-center/resource-load` | 人员负荷 |
| `GET /api/v1/work-center/trends` | 趋势数据 |

## 8. 默认筛选条件

项目工作台默认筛选：

- 我的待办。
- 我负责的项目。
- 超期项目。
- 预警项目。
- 风险项目。
- 非标评审中。
- 报告审核中。
- 付款锁定。

## 9. 一期不做

- 自动排班优化。
- 自动预测所有实验步骤工时。
- 设备与实验步骤深度联动。
- AI 自动判定项目风险原因。

一期先保证人工进度反馈、结构化阻塞、健康度评分和趋势留痕。
