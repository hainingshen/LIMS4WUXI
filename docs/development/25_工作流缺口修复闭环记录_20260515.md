## 2. 已闭环范围

### 2.1 入口、鉴权和路由

- 内部端和客户门户登录态按端隔离。
- 内部端和门户端深链可刷新恢复。
- 门户 token 对内部资源统一返回 403；允许的门户资源按客户范围过滤。
- `workflow-gap-regression.sh` 固化了门户权限边界和工作中心不存在阻塞关闭返回 404。

### 2.2 客户门户

- 支持 Ver.15 动态送检表单保存草稿和正式提交。
- 支持门户项目列表、项目状态、进度、协议入口和报告入口。
- 支持报告草稿预览页、付款门禁提示、正式 PDF 受控下载。
- 支持客户协议确认页和门户侧签署确认。

### 2.3 内部主流程

- 送检受理、项目拆分、非标评审、报价、合同签署锁定已串联。
- 样品接收、照片上传、核验、入库已串联。
- 方案编制、审批、试验下发、工单执行、结果录入、原始记录审核已串联。
- 报告模板、草稿生成、QC/QA/SD 审核、授权签发、付款门禁、绿色通道、正式报告下载和发放日志已串联。
- 报告注册中心、批量下载任务、档案、库存、设备预约、设备文件、留样、客户主数据、系统治理和主数据维护页面已可从对应角色进入。

### 2.4 工作中心

- 工作中心接入真实项目、阻塞、资源负荷和趋势数据。
- 支持新增阻塞、更新阻塞状态、关闭阻塞并要求填写解决说明。
- 本地 smoke 覆盖高严重度阻塞导致项目风险、关闭后恢复正常、趋势中 openBlockers 计数。

### 2.5 MinIO 文件链路

- 样品收样照片通过 `/samples/{id}/photos` 走 multipart 上传。
- 本地 smoke 校验 API 返回值、`file_metadata`、`sample_photo` 和 MinIO 对象字节一致。
- 设备文件、报告模板、报告 PDF、归档和导入导出仍保留文件元数据链路；其中报告 PDF 当前是可验收占位转换，不等同于生产 OnlyOffice 转换质量。

## 4. 当前仍需单独说明的边界

以下内容不阻塞本地闭环验收，但在生产上线前仍需专项确认：

- OnlyOffice 转 PDF 当前为占位适配层，已验证门禁、版本、发放日志和 PDF 响应链路；生产模板渲染质量、签章和版式还需要真实模板联调。
- UI 验收当前是 Playwright 截图和关键控件断言，不是像素级视觉回归。
- 本地 MinIO 已验证样品照片真实对象链路；生产 bucket 策略、备份、生命周期和访问审计需按部署手册复核。
- 当前 smoke 数据是自动化验收数据，不替代客户现场 UAT 的真实样本、真实报告模板和真实角色分工确认。
