# 合同协议模板字段矩阵

## 1. 目的

客户已确认三类项目必须走不同报价、合同模板、报告声明、签章规则和归档要求。本文将现有协议材料结构化，供后续数据库、表单和模板生成使用。

## 2. 协议类型

| 协议类型 | 适用场景 | 是否一期支持 |
| --- | --- | --- |
| 测试委托协议 | 常规单次委托 | 是 |
| 特殊委托/非标协议 | 非标方法、客户提供方法、无资质项目 | 是 |
| 标书、合同评审单 | 合同签署前内部评审 | 是 |
| 分包协议 | 与外部实验室合作 | 管理分包资料和记录，复杂结算后置 |
| 技术合作协议 | 长期合作客户 | 保存协议和按订单关联 |
| 补充协议 | 额外动物、耗材、分包、周期或费用变化 | 是 |

## 4. 合同评审结构化字段

合同评审单中的评审项应做结构化勾选，不只做附件。评审结论字段不使用 boolean，统一使用三态枚举 `YES | NO | NA`，避免不适用项被误判为“不通过”。

| 字段键 | 评审内容 | 类型 |
| --- | --- | --- |
| `withinCapabilityScope` | 检测项目是否在能力范围内 | enum `YES/NO/NA` |
| `requirementsConfirmed` | 客户要求是否已确认 | enum `YES/NO/NA` |
| `instrumentAvailable` | 仪器设备是否满足 | enum `YES/NO/NA` |
| `staffQualified` | 人员能力是否满足 | enum `YES/NO/NA` |
| `deliveryFeasible` | 当前工作量下能否按期完成 | enum `YES/NO/NA` |
| `methodFeasible` | 方法是否可行 | enum `YES/NO/NA` |
| `legalCompliant` | 法规和标准是否符合 | enum `YES/NO/NA` |
| `requiresSubcontract` | 是否需要分包 | enum `YES/NO/NA` |
| `sampleMeetsRequirement` | 样品是否满足要求 | enum `YES/NO/NA` |
| `reviewConclusion` | 评审结论 | enum/text |

## 5. 三类项目模板路由

| 项目类型 | 合同模板 | 报告声明 | 签章规则 |
| --- | --- | --- | --- |
| 标准方法 + 有 CMA/CNAS 资质 | 常规测试委托协议 | 通用资质报告声明 | 按资质报告签章 |
| 标准方法 + 无 CMA/CNAS 资质 | 特殊委托协议或无资质模板 | 无资质/能力声明 | 不得误用 CMA/CNAS 标识 |
| 非标方法 / 客户提供方法 | 非标或特殊委托协议 | 方法来源、责任边界、资质适用性声明 | 按客户确认的非标签章规则 |

报告声明原文以 `09_报告自动生成试点_无菌检查.md` 中声明来源和客户最终确认模板为准。
