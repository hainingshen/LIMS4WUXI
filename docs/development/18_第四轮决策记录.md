# 第四轮决策记录

## 1. 处理原则

第四轮聚焦"是否拍板技术栈和移动端形态"。决策方按 Vibe Coding 实操可行性、移动端覆盖需求和客户快速迭代承诺综合判断，不无条件接受推荐。

## 4. 仍需关注的事项

- 移动端 PWA 起步后，若客户需要原生扫码 / 推送 / 上架商店，二期评估 Capacitor 套壳，技术栈不需要重做。
- OnlyOffice Document Server 是独立服务，部署形态见 16 文档；与 backend 通过内网调用。
- Aviator 规则引擎只用于表达式判断和简单动作；如未来需要复杂编排再评估 Drools，不在一期引入。
- 等保二级要求会反过来约束日志、备份、加密和访问控制；16 文档已纳入。
- Redis 黑名单方案要求 JWT `jti` 字段全网唯一，并在登出 / 强制下线 / 角色变更时写入；00 §10 已明确。
