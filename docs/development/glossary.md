# 术语表

| 术语 | 定义 |
| --- | --- |
| LIMS | Laboratory Information Management System，实验室信息管理系统 |
| SD | Study Director，项目或研究负责人，负责方案和报告关键节点审核 |
| QA | Quality Assurance，质量保证，负责 GLP 和报告质量审核 |
| QC | Quality Control，质量控制，负责报告技术审核和记录复核 |
| GLP | Good Laboratory Practice，良好实验室规范 |
| CMA | 中国检验检测机构资质认定标志 |
| CNAS | 中国合格评定国家认可委员会认可 |
| SOP | Standard Operating Procedure，标准操作规程 |
| 非标方法 | 客户提供方法或不属于既有标准方法的检测方法 |
| 标准有资质项目 | 标准方法且实验室具备对应 CMA/CNAS 资质的项目 |
| 标准无资质项目 | 标准方法但不在实验室 CMA/CNAS 资质范围内的项目 |
| 送检单 | 客户提交的样品、报告、试验项目和处置要求表单 |
| 委托协议 | 客户和实验室签署的测试委托文件 |
| 流转单 | 样品、检测项目、工单、报告和归档的内部流转记录 |
| 置样 | 试验前按要求对样品进行条件处理或放置的独立任务 |
| 领样 | 检测人员从样品管理环节领取试验所需样品 |
| 原始记录 | 检测过程、环境、设备、试剂、结果和签名的第一手记录 |
| 检测子项 | 为达成检测目标而设计的标准化操作单元 |
| 检测项目 | 由一个或多个检测子项组成的完整检测方案 |
| 工作中心 | 展示项目健康度、卡点、Owner、人员负荷和趋势的管理界面 |
| 绿色通道 | 未到账先发电子正式报告的例外审批流程 |
| 付款门禁 | 未到账时锁定正式报告下载、电子签章发放、纸质报告打印和样品退还 |
| 报告版本 | 报告草稿、正式签发、作废、重新签发形成的版本链 |
