# 送检单 Ver.15 字段映射

## 1. 设计原则

送检单是客户门户表单、项目建档、样品建档、报告字段和合同字段的重要来源。一期不得只做一个自由文本附件上传。

实现原则：

- 中英文双栏字段必须拆成 `*_zh` 和 `*_en`。
- 必填字段后端强校验。
- 枚举字段使用数据字典。
- 字段归属以 `specs/submission_ver15_fields.csv` 的 `entity` 列为权威。
- 字段锁定策略以 `specs/submission_ver15_fields.csv` 的 `lock_policy` 列为权威。
- PART 6 的 GLP 声明作为独立确认记录。
- PART 7 和 PART 8 的试验矩阵进入检测项目选择模型，不只保存图片或附件。

## 8. PART 7 生物相容性试验矩阵

试验矩阵不直接落为单列文本，采用 `submission_test_selection` 明细表：

| 字段键 | 类型 | 说明 |
| --- | --- | --- |
| `submissionId` | uuid | 送检单 |
| `category` | enum | `BIOCOMPATIBILITY` |
| `testName` | string | 试验名称 |
| `methodName` | string | 方法 |
| `extractant` | string | 浸提介质 |
| `standard` | string | 参照标准 |
| `instruction` | text | 送检说明 |
| `note` | text | 备注 |

一期需配置的生物相容性试验项：

| 试验名称 | 典型方法/子项 | 关键附加字段 |
| --- | --- | --- |
| 细胞毒性 | MTT、其他 | 含血清 MEM、不含血清 MEM、不浸提 |
| 刺激 | 急性接触、重复多次接触 | 极性、非极性、不浸提 |
| 致敏 | GPMT、Buehler Test | 极性、非极性、不浸提 |
| 急性毒性 | 静脉、腹腔、经口 | 给药途径 |
| 热原 | 兔法、细菌内毒素 | 限值 |
| 亚急性/亚慢性/慢性毒性 | 注射、经口、皮下植入等 | 周期、临床最大剂量 |
| 遗传毒性 | AMES、CA、MLA、MN | OECD 标准 |
| 植入 | 肌肉、皮下、骨、脑 | 周期 |
| 血液相容性 | 溶血、凝血、血小板、补体等 | 方式 |
| 降解性能 | 体外、体内 | 周期 |
| 化学表征 | 化学表征 | 具体项目 |

## 9. PART 8 微生物/包装/物理/其他试验矩阵

同样采用 `submission_test_selection` 明细表，`category` 可取：

- `MICROBIOLOGY`
- `PACKAGING`
- `PHYSICAL`
- `CHEMICAL`
- `OTHER`

一期需配置的典型项目：

| 试验名称 | 方法/子项 | 关键附加字段 |
| --- | --- | --- |
| 初始污染菌 | 平板计数、薄膜过滤、MPN | 方法适用性、校正因子 |
| 微生物限度 | 微生物计数、控制菌检查 | 控制菌种类 |
| 无菌测试 | 直接接种、薄膜过滤 | 是否方法适用性 |
| 菌种鉴定 | VITEK 等 | 菌株包装说明 |
| 清洗效果验证 | ATS | 清洗方式、清洗剂 |
| 消毒效果验证 | 低/中/高水平消毒 | 消毒方式、消毒剂 |
| 灭菌效果验证 | 化学、高压蒸汽 | 灭菌方式 |
| 包装验证 | 加速老化、气泡、染料渗漏、密封强度、模拟运输等 | 样品量、测试节点 |
| 辐照剂量设定/审核 | VDmax、Method 1 等 | 辐照方、批号、数量 |
| ISO 18562 | 颗粒物、VOC、冷凝液可浸出物 | 气路密度、接触时长 |
| 手套物理性能 | 尺寸、水密性、拉伸、老化 | 批量、参照标准 |
| 其他试验 | 由客户填写 | 试验、方法、标准、备注 |

## 10. 可机读 CSV

同目录下提供可由 Excel 打开的种子表：

- `specs/submission_ver15_fields.csv`

后续实体、DTO、前端表单、校验规则和变更锁定策略以该 CSV 为第一版字段清单。

`lock_policy` 说明：

| 值 | 含义 |
| --- | --- |
| `HARD_LOCK` | 报告后不可修改，如样品批号 |
| `CHANGE_REQUEST` | 合同或方案签署后必须走变更申请 |
| `FREELY_EDITABLE` | 内部操作字段或非核心备注，可按权限编辑 |
